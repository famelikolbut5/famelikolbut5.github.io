# Артур Колесников

Личный сайт разработчика: Python, веб-приложения, AI и автоматизация. Шесть проектов с интерфейсами и ссылками на исходники, опыт работы, навыки, сертификаты и контакты.

**Сайт:** [87.199.129.61](http://87.199.129.61/)

## Как устроен сайт

Статические HTML, CSS и JavaScript. Локальные шрифты и изображения, адаптивная сетка, анимация первого экрана, просмотр проектов и сертификатов. Учитывается настройка уменьшения анимации.

Сервер приложения, база данных и сборщик для запуска не требуются. Демо-приложения находятся в отдельных репозиториях; здесь размещены их изображения и описания.

## Структура

```text
index.html         содержание и разделы сайта
style.css          оформление и адаптивные правила
script.js          просмотр проектов и сертификатов
assets/            изображения и локальные шрифты
FONT_LICENSES.txt  лицензии шрифтов
ASSETS.md          сведения о материалах
```

## Локальный запуск

```sh
git clone https://github.com/famelikolbut5/famelikolbut5.github.io.git
cd famelikolbut5.github.io
python -m http.server 8080 --bind 127.0.0.1
```

Откройте [localhost:8080](http://localhost:8080).

## Размещение

Сайт обслуживается Nginx как набор статических файлов. Для обновления достаточно заменить HTML, CSS, JavaScript и материалы в `assets/`.
